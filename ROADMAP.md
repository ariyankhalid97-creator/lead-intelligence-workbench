# Roadmap

This roadmap tracks useful, bounded improvements without weakening the project's evidence and privacy rules.

## Near term

- Expand deterministic provider contract tests and provider-health diagnostics.
- Add a first-run guided tour using synthetic sample data.
- Improve export schemas for CRM imports while retaining source provenance.
- Add more official registry adapters with country-specific normalization.
- Improve accessibility for keyboard-only navigation and screen readers.
- Add signed Windows release artifacts when a signing identity is available.

## Community opportunities

- New niche packs with documented terminology and exclusions.
- Additional public directory metadata and official registry references.
- Translation of setup documentation and interface copy.
- Reproducible fixtures for changing public-provider schemas.
- Performance profiling for large research libraries.

Open or vote on an issue before beginning a substantial roadmap item so work is not duplicated.

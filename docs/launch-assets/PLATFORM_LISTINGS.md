# Platform-specific launch package

## Product Hunt

**Product name**

Lead Extractor

**Tagline**

Local-first lead research without subscriptions

**Description**

Lead Extractor finds, verifies, deduplicates, and organizes public business leads across multiple sources. It runs on Windows, keeps research local, supports optional Ollama AI, and gates Zoho outreach behind your approval.

**Pricing**

Free

**Launch tags**

- Sales
- Artificial Intelligence
- GitHub

**Product categories**

- Lead generation software
- AI sales tools
- Browser Automation

**Maker comment**

Hi Product Hunt! I built Lead Extractor because most lead tools either lock useful research behind subscriptions or return a messy list with little evidence.

Lead Extractor is a free, open-source Windows workspace that brings discovery, verification, deduplication, research organization, and approval-gated outreach into one local-first workflow. It can use public sources such as Chrome Maps, OpenStreetMap, web discovery, Wikidata, and NPI; optional local Ollama models help with search planning and lead review without requiring a cloud AI account.

This first public release includes a desktop installer, grouped research history, evidence-aware diagnostics, email quality checks, browser-assisted verification, and Zoho outreach that stays behind explicit approval.

I would especially value feedback on source coverage, verification quality, and which workflows would make it most useful for independent operators and small agencies.

## Microns

Microns is not currently an eligible channel unless the product has verifiable revenue and is profitable. Its seller flow explicitly accepts only profitable, bootstrapped startups and redirects pre-revenue projects to PreRevMarket.

Do not create a Microns listing until the following facts are available and supported:

- trailing-12-month revenue;
- trailing-12-month profit and expenses;
- paying-customer count;
- traffic or download evidence;
- asking price;
- a complete transferable-asset list;
- seller risks and mitigations.

The existing source code is publicly released under the MIT License. Any eventual acquisition listing must disclose that buyers cannot receive exclusivity over code that has already been published under MIT. Transferable value can instead include the brand, repository administration, release pipeline, future development, documentation, installer workflow, and any later customer or distribution assets.

**Market fit when eligible**

- Business type: Windows desktop software / lead-generation tool
- Buyer profile: sales-tech founder, agency owner, data-tool operator, or micro-SaaS acquirer
- Core angle: local-first alternative to subscription lead databases
- Monetization paths: paid managed edition, premium verification sources, agency workspaces, hosted enrichment, onboarding/support, or vertical data packs
- Principal risks: source reliability, browser anti-automation controls, public-data compliance, unsigned installer reputation, and dependence on user-managed browser sessions

# Lead Extractor 2.6.0

Lead Extractor 2.6.0 introduces a professional workspace redesign and a private local-AI consistency brain.

## Highlights

- A high-contrast neutral workspace with the existing compact dark sidebar preserved.
- Clearer search, source, library, results and outreach hierarchy at adjustable desktop sizes.
- Niche-scoped local memory built from aggregate completed-run statistics and reviewed feedback.
- Prompt-time retrieval for consistent planning and evidence interpretation without fine-tuning Ollama.
- Strict privacy boundaries: lead identities, contacts, URLs and page text are excluded from consistency memory.
- Visible memory confidence, contributing runs, feedback totals and manual refresh.

## Safety and evidence

Memory is historical guidance, not lead evidence. Current-run evidence IDs, literal excerpts and deterministic validators remain authoritative. The application still cannot bypass security checkpoints or send outreach without explicit approval.

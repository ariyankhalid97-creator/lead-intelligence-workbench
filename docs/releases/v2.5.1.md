# Lead Extractor 2.5.1

Lead Extractor 2.5.1 improves repeated discovery, LinkedIn-assisted company research and Google Sheets continuity while keeping public actions approval-gated.

## Highlights

- Repeated niche-and-location searches continue with unseen businesses instead of returning the first batch again.
- Cross-source identity memory suppresses previously retained businesses and records source exhaustion explicitly.
- Google Maps continuation searches scroll beyond earlier observed listings.
- Verified company LinkedIn URLs can feed a separate, resumable public employee-discovery worksheet.
- Visible employee headlines are normalized into role, seniority, priority and evidence-derived tags.
- Second-round verification refreshes current Google Sheets data automatically.
- LinkedIn and Google security checkpoints pause for manual action rather than being bypassed.
- Employee totals and tablet-sized desktop layouts now restore correctly.

## Installation

Download `Lead-Extractor-Setup-2.5.1.exe` and verify its SHA256 value against `Lead-Extractor-Setup-2.5.1.exe.sha256` before running it.

The build is not currently code-signed, so Windows may display an unfamiliar-publisher warning.

## Privacy boundary

No local searches, leads, browser profiles, credentials, logs, spreadsheets or outreach content are included in this release. See [SECURITY.md](../../SECURITY.md) and the full [CHANGELOG.md](../../CHANGELOG.md).

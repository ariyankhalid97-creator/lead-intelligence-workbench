# Code of Conduct

## Our standard

Lead Extractor is an open-source project for respectful, lawful business research. Contributors and community members are expected to be constructive, patient and precise.

Examples of welcome behavior include:

- Giving actionable technical feedback.
- Respecting different experience levels and viewpoints.
- Correcting mistakes without personal attacks.
- Protecting private data and reporting security concerns responsibly.
- Keeping public examples free of real credentials, contacts and campaign content.

Unacceptable behavior includes harassment, discriminatory language, threats, deliberate disruption, publishing another person's private information, or using the project community to facilitate abuse or unlawful data collection.

## Enforcement

Project maintainers may edit or remove contributions, comments, issues or other participation that violates this standard. Repeated or serious violations may result in temporary or permanent exclusion from project spaces.

Report conduct concerns privately to the maintainer through the contact method listed on the maintainer's GitHub profile. Do not include passwords, access tokens or unrelated personal data in a report.

This code applies in project spaces and when someone publicly represents the project.

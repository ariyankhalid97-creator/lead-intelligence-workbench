# Support

## Start here

- Read the installation and troubleshooting sections in [README.md](README.md).
- Search existing [issues](https://github.com/ariyankhalid97-creator/lead-intelligence-workbench/issues) and [Discussions](https://github.com/ariyankhalid97-creator/lead-intelligence-workbench/discussions).
- Export Run diagnostics when reporting a provider failure, then remove contact data, credentials, cookies and local paths before sharing it.

## Where to ask

- **Questions and use cases:** GitHub Discussions.
- **Reproducible software defects:** the bug report form.
- **New public data source:** the data-source request form.
- **Security vulnerability:** follow [SECURITY.md](SECURITY.md); do not publish exploit details or secrets in an issue.

Coverage from public sources varies by niche, country and provider availability. A low result count is not automatically a software defect; include the niche, country, city, selected sources and sanitized diagnostics so the cause can be distinguished.
